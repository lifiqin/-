# Synthetic Test Asset

This directory contains a hand-authored schematic and matching metadata.
The scene is entirely synthetic; it was not derived from project photographs,
videos, labels, or other private test material.

Use it only for format, coordinate, and loader smoke checks. It is not a
golden fixture, a detector-accuracy benchmark, or evidence about a real site.
No real people, company marks, license plates, or location details are present.

- `scene.svg`: 640 x 360 vector schematic.
- `sample.json`: synthetic object boxes in pixel coordinates, origin at top-left.
